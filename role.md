Raw Record Schema (TV1 -> TV2): JSON chứa danh sách PaperRecord đã parse với paper_id ổn định.
Clean Dataset Schema (TV2 -> TV3, TV4): CSV/JSON gồm các cột: paper_id (unique, non-null), title, summary, published, authors_joined, categories_joined, age_days, text_for_embedding, abs_url, pdf_url.
Evaluation Set (TV2 -> Trưởng nhóm & Evaluation): File test_set.json cố định chứa: id, question_type, question, ground_truth, ground_truth_doc_ids.
